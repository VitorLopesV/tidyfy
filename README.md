# Tidyfy

Projeto Java 21 com Maven.

## Requisitos

- JDK 21
- Maven 3.8+

## Comandos

```bash
mvn clean test      # compila e roda os testes
mvn clean package   # gera target/tidyfy-1.0-SNAPSHOT.jar
java -jar target/tidyfy-1.0-SNAPSHOT.jar
```

## Estrutura

```
src/main/java/com/tidyfy/   código da aplicação
src/test/java/com/tidyfy/   testes (JUnit 5)
```
