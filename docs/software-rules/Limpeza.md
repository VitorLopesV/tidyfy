# Limpeza

Tipo de [[Ajudante]] que esvazia a [[Lixeira]] ou remove os arquivos de uma pasta.

## Regras
- **Alvo:** a [[Lixeira]] ou uma pasta.
- **Lixeira:** remove de forma permanente; a idade conta do dia em que o arquivo foi para lá.
- **Pasta:** move os arquivos para a [[Lixeira]] (recuperáveis); atua só nos arquivos soltos, sem tocar nas subpastas.
- **Quanto limpar:** tudo, ou só o que é mais antigo que N dias (N ≥ 1).
- **Referência de idade (só pasta):** o usuário escolhe se conta da criação ou da última modificação.

Veja também [[Pastas sensíveis]].
