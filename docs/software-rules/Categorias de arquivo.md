# Categorias de arquivo

Catálogo padrão da [[Organização de pasta]]; o usuário não cria categorias próprias.

- Imagens: jpg, jpeg, png, gif, bmp, webp, svg, heic, tiff, ico
- Vídeos: mp4, mkv, avi, mov, wmv, flv, webm, m4v
- Documentos: pdf, doc, docx, xls, xlsx, ppt, pptx, txt, rtf, odt, ods, odp, csv
- Compactados: zip, rar, 7z, tar, gz
- Executáveis: exe, msi, bat
- Pastas e Outros: veja [[Organização de pasta]]

## Regras
- Cada extensão pertence a uma única categoria.
- Extensões são comparadas em minúsculas e sem ponto (Foto.JPG vira jpg).
