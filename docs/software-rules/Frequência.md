# Frequência

Quando o [[Ajudante]] roda.

## Regras
- A cada N dias, com N ≥ 1 e sem limite máximo; quem define é o usuário.
- Um ou mais horários do dia, sem repetir.
- **Data de início:** dia em que o ajudante foi salvo ou teve a frequência alterada; é a partir dela que se conta "a cada N dias".

Cada horário vira um gatilho no [[Agendador do Windows]].
