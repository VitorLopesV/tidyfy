# Organização de pasta

Tipo de [[Ajudante]] que move os arquivos de uma pasta para subpastas por tipo, usando as [[Categorias de arquivo]].

## Regras
- Olha só o que está diretamente na pasta; não entra em subpastas.
- Pastas soltas (que o ajudante não criou) vão inteiras para a subpasta "Pastas".
- Extensão desconhecida vai para "Outros" (inclusive músicas).
- As subpastas do próprio ajudante (categorias, Pastas e Outros) ficam onde estão; uma pasta do usuário com o mesmo nome de uma categoria conta como do ajudante.
- **Conflito de nome no destino:** se o conteúdo é igual (duplicado), o arquivo de fora vai para a [[Lixeira]]; senão o item movido ganha um número no fim (teste(1).pdf, teste(2).pdf...), inclusive pastas em "Pastas".

Veja também [[Pastas sensíveis]].
