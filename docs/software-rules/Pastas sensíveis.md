# Pastas sensíveis

Pastas que nenhum [[Ajudante]] pode usar.

- Recusadas com tudo que há dentro: C:\Windows, C:\Program Files, C:\Program Files (x86) e C:\ProgramData.
- Recusadas só elas mesmas: a raiz de qualquer disco e a pasta do usuário (as pastas dentro dela, como Downloads, são aceitas).
